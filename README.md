# OWASP-JUICE-SHOP

## Overview

This repository contains my learning notes, challenge solutions, and security testing exercises performed on the OWASP Juice Shop application.

OWASP Juice Shop is a deliberately vulnerable web application designed for security training, penetration testing practice, and awareness of common web application vulnerabilities.

## Objectives

* Learn web application security concepts
* Practice ethical hacking techniques
* Understand common OWASP Top 10 vulnerabilities
* Develop penetration testing methodology
* Improve bug bounty hunting skills

## About OWASP Juice Shop

OWASP Juice Shop is an open-source insecure web application maintained by the Open Worldwide Application Security Project (OWASP).

The application includes vulnerabilities such as:

* SQL Injection
* Cross-Site Scripting (XSS)
* Broken Authentication
* Broken Access Control
* Security Misconfigurations
* Sensitive Data Exposure
* Server-Side Request Forgery (SSRF)
* Cross-Site Request Forgery (CSRF)
